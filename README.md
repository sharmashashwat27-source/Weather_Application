# Weather Application

A simple desktop weather application built with Python, PyQt6, and the OpenWeatherMap API. Enter a city name to view real-time weather information, including temperature, weather conditions, and weather icons.

## Features

* Real-time weather data
* Temperature displayed in Celsius
* Weather condition descriptions
* Weather emojis/icons based on current conditions
* Clean and responsive PyQt6 interface
* Error handling for invalid city names and network issues
* Automatic temperature conversion from Kelvin to Celsius

## Tech Stack

* Python
* PyQt6
* Requests
* OpenWeatherMap API
